# Resonant Arcana

Resonant Arcana adds elemental spells, rituals, and legendary spellbooks to Iron’s Spells ’n Spellbooks. Installing Alex’s Caves or Bosses’Rise unlocks themed spells.

Requires Minecraft 1.21.1, NeoForge 21.1.219+ (21.1.x), and Iron’s Spells ’n Spellbooks 3.16.3+ (3.16.x) with its required dependencies.
