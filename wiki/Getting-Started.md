# Getting started

| Required | Supported version |
| --- | --- |
| Minecraft / Java | 1.21.1 / Java 21 |
| NeoForge | 21.1.219 or later within 21.1.x |
| Iron’s Spells ’n Spellbooks | 1.21.1-3.16.3, with its required dependencies |

Install the same Resonant Arcana version on **client and server**. Equip an inscribed spellbook in the **Curios spellbook slot** and use Iron’s normal casting controls.

| Optional addon | Unlocks |
| --- | --- |
| Bosses’Rise 2.1.2 | 17 boss arts for Kraken, Yeti, Helvar, Sandworm and Dragon |
| Alex’s Caves 2.0.10 + Citadel | 24 cave arts across all six cave areas |
| AAAParticles | Selected ritual seals and Doom effects |

**Both gameplay addons are optional.** The core mod works without them; unsupported addon versions leave the corresponding adapter disabled.

## Your first spellbook

1. Obtain a compatible Iron’s spellbook or craft one of the three legendary books.
2. Obtain a scroll through the Scroll Forge or the addon’s themed recipes.
3. Inscribe it at Iron’s inscription table, then equip the book in the Curios spellbook slot.
4. Use Iron’s normal spell selection and casting controls. Holding the book alone does not activate its equipped perks.

The debug wand is a creative testing item. Press **X** while using it to browse and search enabled spells.

## Updating older worlds

Back up the world before updating. Version 0.13 changed the registry namespace to `resonant_arcana` without legacy migration. Version 0.21 retired the ten school wands; current equipment is three inscribable books and one debug wand.
