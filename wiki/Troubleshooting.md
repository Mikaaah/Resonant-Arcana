# Troubleshooting

| Problem | Check |
| --- | --- |
| A cave or boss spell is missing | Use Alex’s Caves 2.0.10 or Bosses’Rise 2.1.2 and their dependencies on both client and server. Unsupported versions disable that adapter. |
| Equipped perks do not apply | Put the spellbook in the Curios spellbook slot. Holding it alone is insufficient. |
| A ritual stops before release | Check mana, cooldown, interruption and target cover. God rituals use the ground mark selected at cast start. |
| A seal is missing | Selected seals require AAAParticles. Core native particle effects do not. |
| A spell is hidden | Check the server’s spell settings and optional-mod gates, then search the single Spells creative tab or debug archive. |

For a report, include the mod versions, spell ID and rank, equipment, reproducible steps, crash report or latest log, and a short recording for visual issues.
